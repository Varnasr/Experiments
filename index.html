Tools

Court Petition Translator AI Tool

Translates Hindi Supreme Court and High Court petitions into formal legal English. Handles the legalese — yaachikaakartha becomes "Petitioner", anuchhed becomes "Article" — so the output reads like it was drafted in English.

Sarvam AI · Llama 3.3 70B via Groq · Netlify Functions

Drive PDF Extractor Tool

Headless-browser CLI for downloading view-only Google Drive PDFs. Scrolls the Drive viewer, captures each page from the rendered canvas, and reassembles them into a fresh PDF — no Drive auth required.

Node · Playwright · jsPDF

Creative

Kundendu's Learn & Play Creative Tool

A playful Class 1 CBSE worksheet generator — English phonics and reading, Hindi, Maths, and EVS. Freshly randomised questions every time, three difficulty levels, on-screen answer checking with confetti, printable sheets with answer keys, and a practice-history tracker.

HTML · CSS · JavaScript · no dependencies

Nilaya E-Pothi Creative

A small family library, kept in this house. A parchment-styled e-library with searchable catalogue, themed browsing, reading tracker, and a network map of books linked by themes, keywords, and authors.

HTML · Tailwind · D3 · FlexSearch
